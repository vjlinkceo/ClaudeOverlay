# Идеи на будущее — пока не реализованы

В версии 3.2 уже добавлены компактное окно, запоминаемая область и вопрос голосом по удержанию клавиши.

Остальные предложения оставлены на будущее:

1. Запоминать модель и глубину рассуждения отдельно для каждого режима.
2. Добавлять модели через настройки без изменения исходников.
3. По желанию сохранять полную историю чатов, искать по ней и продолжать после перезапуска.
4. По желанию жёстко блокировать запросы после достижения лимита расходов.
5. Подключить локальную модель для ответов без облачного API.

Эти пункты не внедрены.

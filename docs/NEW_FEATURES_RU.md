# Новые функции ChatGPT Overlay 3.2

Изменения внесены в `C:\Users\vadim\Desktop\overlay\ClaudeOverlay`. Запуск — `start.bat` в этой папке; повторная установка зависимостей не нужна.

## Компактное окно

Нажмите **Ctrl+Alt+C** или кнопку **▣** в заголовке. В компактном виде остаются последний ответ, небольшая строка ввода, голосовой вопрос и захват области. Повторное нажатие вернёт полный интерфейс с историей и черновиком. Размеры и положение двух видов запоминаются отдельно при закрытии. Переключатель также есть в **Настройки → Окно**.

## Запоминаемая область

Первое **Ctrl+Alt+R** или нажатие **Область** предложит выделить прямоугольник. Следующие нажатия снимают ту же область и отправляют её в запрос.

Чтобы заменить область, нажмите **Ctrl+Alt+Shift+R** или **Область ▾ → Выбрать новую область**. В этом меню можно забыть область. Esc при выделении отменяет выбор и сохраняет прежнюю область. Если монитор отключён или координаты больше не помещаются на экран, программа попросит выбрать область заново.

## Вопрос голосом

Зажмите **Ctrl+Alt+V** или кнопку **Голос**, дождитесь надписи «Записываю вопрос», произнесите вопрос и отпустите. После отпускания запись сразу идёт в локальное распознавание, затем вопрос отправляется выбранной модели. Набранный текст в поле ввода остаётся на месте.

Кнопка **■** или Esc, когда активно окно программы, отменяет запись или распознавание. Голосовые вопросы распознаются тем же локальным Whisper, что и обычное прослушивание. При первом использовании может потребоваться скачивание модели. У записи есть предел 45 секунд: при его достижении запись прекращается без отправки и предлагается задать вопрос короче.

Все сочетания меняются в **Настройки → Горячие клавиши**.

## Что ускорено

- События от рабочих потоков сразу будят интерфейс через Qt, вместо ожидания очередного 20-миллисекундного опроса.
- Первый фрагмент ответа рисуется сразу, без дополнительного 40-миллисекундного таймера. Последующие части объединяются, чтобы не перегружать окно.
- Невидимое представление чата не перерисовывает каждый фрагмент потока.
- Ручной голосовой вопрос идёт раньше ожидающих фоновых фраз, использует уже загруженную модель и не ждёт паузу детектора речи после отпускания.
- Для устройств звука по умолчанию убрано ненужное перечисление всех устройств.

В локальном сравнении одинаковых 60 событий медианная задержка доставки в интерфейс сократилась с **15.95 мс до 0.11 мс**. Это измерение только очереди интерфейса, не времени ответа модели и не распознавания голоса. Качество изображения, модель и глубина рассуждения ради этого ускорения не снижались.

Общая длительность по-прежнему зависит от загрузки модели речи, CPU/GPU, сети и сервиса ИИ. Реальную скорость ответа облачного API в этой проверке не измеряли. Принципы оптимизации API сверены с [официальной документацией OpenAI](https://developers.openai.com/api/docs/guides/latency-optimization).

## Проверки

Автотесты покрывают компактный режим и возврат истории, отдельную геометрию, немедленный первый фрагмент, сохранение и проверку области, нажатие/отпускание горячей клавиши, запись и отмену, приоритет распознавания и сохранность черновика. Запись тестируется на синтетическом звуке, облачные запросы — на имитации API. Внешний вид окон проверен по изображениям.

Итог проверки версии 3.2: 171 тест прошёл, пропущенных тестов нет. Проверки Ruff, форматирования изменённых файлов и pip check прошли.

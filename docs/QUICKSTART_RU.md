## Подключение

1. Запустите `start.bat` в папке программы.
2. В окне подключения выберите **OpenAI / ChatGPT**.
3. Создайте ключ в [OpenAI API Keys](https://platform.openai.com/api-keys), настройте оплату API и вставьте ключ в программу. Подключение использует OpenAI API с отдельной оплатой API.
4. Нажмите **Check / Проверить**, затем **Save and continue / Сохранить и продолжить**. Проверка ключа подтверждает доступ к модели, но не проверяет баланс и все разрешения на генерацию.
5. Если окно подключения не открылось, нажмите ⚙ → **Model / Модель** → **API key… / API-ключ…**. Там же можно заменить ключ.

В настройках окна можно выбрать русский интерфейс; для смены языка перезапустите программу.

По умолчанию выбрана **GPT-5.4 mini**. Режим **Solve / Решить** и кнопка **Deeper / Глубже** используют **GPT-5.5**. Модели Anthropic сохранены в списке и требуют своего ключа. Переключение режимов остаётся в пределах выбранного сервиса.

## Новые сочетания

- `Ctrl+Alt+C` — компактное / полное окно.
- Удерживать `Ctrl+Alt+V` — задать вопрос голосом; отпустить — отправить.
- `Ctrl+Alt+R` — выбрать область при первом использовании, затем снимать её повторно.
- `Ctrl+Alt+Shift+R` — выбрать новую область.

## Использование

- Введите вопрос и нажмите Enter.
- **Screen / Скрин**, `Ctrl+Alt+S` — отправить скриншот; **Area / Область**, `Ctrl+Alt+R` — выбрать область.
- **Listen / Слушать**, `Ctrl+Alt+L` — распознавать звук; при первом включении программа скачает модель речи.
- `Ctrl+Alt+A` — ответить по услышанному; `Ctrl+Alt+M` — пересказ.
- Esc или ■ — остановить ответ; `Ctrl+Alt+H` — скрыть/показать окно.

Основной интерфейс сохранён. Добавлены выбор сервиса, модели OpenAI, ввод и смена ключей в настройках, обработка ошибок OpenAI и расчёт расходов по его токенам.

## Ключи и данные

Ключ OpenAI хранится в `openai_api_key.dpapi`; Anthropic — в прежнем `api_key.dpapi`. Оба шифруются Windows DPAPI. Можно задать ключ в `.env` как `OPENAI_API_KEY=…` или `ANTHROPIC_API_KEY=…`: при успешном шифровании значение из `.env` очищается. Переменная окружения Windows для соответствующего сервиса имеет приоритет над файлом и сохранённым ключом.

Звук распознаётся локально. Текст, изображения, профиль и история запроса отправляются сервису выбранной модели. При смене сервиса прежняя текстовая история и изображения перейдут новому сервису со следующим запросом. Запросы OpenAI используют `store=False`; это не отменяет правил обработки данных на стороне сервиса.
